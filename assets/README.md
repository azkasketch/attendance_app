# Assets Directory

This directory contains static assets for the application.

## Assets

This directory is reserved for future assets. The app currently uses Material Design icons and does not require custom assets.

## Instructions

If you wish to add custom assets:
1. Place image files in `assets/images/`
2. Update `pubspec.yaml` to include the assets
3. Reference assets in your code using `AssetImage` or `Image.asset`

## Note

The app uses built-in Material Design icons and does not currently require custom assets.
